# Academic Logic Lab — C++ Programming Exercises

Object-oriented and procedural C++ exercises covering basic algorithms,
computational math, and data processing pipelines.

## Files

| File | Concept | What it covers |
|---|---|---|
| `oop_shapes.cpp` | Object-oriented programming | Abstract base class, inheritance, virtual functions/polymorphism |
| `math_operations.cpp` | Computational math | Prime checking, GCD/LCM (Euclidean algorithm), mean/variance statistics |
| `data_processing.cpp` | Procedural data flow | A load → process → report pipeline over student records |
| `debugging_exercise.cpp` | Debugging & troubleshooting | A commented-out buggy version alongside the fixed version, with the troubleshooting steps documented inline |
