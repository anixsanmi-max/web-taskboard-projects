# Habitloop — Web Dev Practice Project

**Live demo:** https://anixsanmi-max.github.io/web-taskboard-projects/Habitloop/

A personal habit-tracker mockup built to practice semantic HTML5, responsive
CSS3, and vanilla JavaScript interactivity — no frameworks.

## What it demonstrates

- **Semantic HTML5**: proper use of `header`, `nav`, `main`, `section`, `article`, `footer`, with ARIA labels for accessibility
- **Responsive CSS3**: CSS Grid layout, `clamp()` for fluid spacing/type, a mobile breakpoint, `prefers-reduced-motion` support
- **Interactive JS components**:
  - Dark/light theme toggle (persisted in `localStorage`)
  - Single-open accordion (FAQ section)
  - Modal dialog for adding a habit
  - Client-side form validation
  - A habit list with add/complete/delete, persisted in `localStorage`
  - An animated SVG "streak ring"

## Run it

Open `index.html` in a browser — no build step, no dependencies.
