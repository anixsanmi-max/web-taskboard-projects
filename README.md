# Web Projects

A collection of web development projects — frontend, full-stack, and backend work.

## Projects

### [Task Board](./task-board)
A full-stack task/board manager with account signup/login, session-based authentication, and a SQLite-backed REST API.

**Live demo:** https://web-taskboard-projects.onrender.com
**Tech:** Node.js, Express, SQLite, bcrypt, express-session, vanilla JavaScript

### [Calculator App](./calculator-app)
A calculator with a hand-written expression parser (no `eval()`), full keyboard support.

**Live demo:** https://anixsanmi-max.github.io/web-taskboard-projects/calculator-app/
**Tech:** HTML5, CSS3, JavaScript
